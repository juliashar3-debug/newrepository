# Обслуживание сайта СМС

1. Прочитай `AGENTS.md`, `webapp/README.md`, `docs/TOOLKIT.md` и при публикации `webapp/PUBLIC-SITE.md`. Проверь ветку, изменения пользователя и фактическую среду.
2. Различай компьютер пользователя, облачную рабочую копию и GitHub Pages. `127.0.0.1:8765` доступен на машине с запущенным сервером; это не внешний адрес.
3. Установка всего набора: `python tools/install_tools.py`. На Windows — `INSTALL-TOOLS-WINDOWS.bat`. Библиотеки находятся в `webapp/.venv`; базовый запуск сайта — `START-WINDOWS.bat`.
4. Диагностика: `python tools/check_tools.py`. Проверяй программы, браузер и OCR отдельно от наличия Python-пакетов. Не выводи API-ключи и не добавляй их в Git.
5. Перед переносом пользовательской `.data` останови локальный сервер и сохрани полную резервную копию. Переноси `.data` до первого запуска новой версии, не заменяй её начальным журналом репозитория.
6. При ошибке PDF используй конкретный этап и код из `webapp/export-pdf.ps1`. PowerPoint может ожидать первый запуск или активацию; не объявляй его отсутствующим по одной ошибке экспорта. Не завершай чужие открытые презентации.
7. Выполни проверки, соответствующие изменению. При обновлении генератора проверь настоящие PPTX/PDF; изменения браузерного интерфейса проверь в браузере.
8. Публикация просмотра: `python tools/build_public_site.py --output EMPTY_DIR`, затем workflow `Publish SMS journal`. Готовый локальный каталог или успешный git push не означает успешного развёртывания.
9. Проверь итог workflow и фактический адрес. Если настройки Pages, права или тариф блокируют публикацию, назови конкретную ошибку и необходимые действия владельца. Не меняй видимость всего репозитория без отдельного разрешения на раскрытие его содержимого.
10. Сохраняй разрешённые изменения обычным commit/push после проверки удалённой ветки. Не включай `.data`, `.venv`, ключи и временные проверки. Авторизация пользователя в текущей сессии сохраняется; не запрашивай её повторно для уже согласованных действий.

Результат: установленный или обновлённый код, проверенное состояние и короткая инструкция. Ссылка на сайт выдаётся как рабочая только после подтверждения публикации.
