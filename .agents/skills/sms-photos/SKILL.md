# Фото для отчёта

1. Прочитай `AGENTS.md` и карточку мероприятия. Открой изображения перед выбором и кадрированием. Не определяй личности людей.
2. Сохраняй оригиналы в квартале события. Подготовку выполняй над отдельными копиями. Для JPEG/PNG/WebP используй Pillow; для HEIC/HEIF сначала `pillow_heif.register_heif_opener()`.
3. Учитывай EXIF-ориентацию через `ImageOps.exif_transpose`. Сохраняй пропорции и достаточное разрешение; не растягивай изображение до размеров рамки.
4. Из трёх снимков общий поставь в центр, процесс и отдельных участников — сверху и снизу. Сравни варианты и проверь, не закрывает ли изогнутая граница лица.
5. Повторное использование той же фотографии проверяй по SHA-256 оригинала. Разные кадры одной сцены автоматически дублями не считай.
6. Для отчёта используй функции обработки изображений в `webapp/report_builder.py`, сохраняя утверждённые рамки и композицию. Для публичного сайта `tools/build_public_site.py` создаёт отдельные JPEG без EXIF.
7. Число людей оценивай только по просьбе пользователя и по одному выбранному общему фото. Не суммируй одних людей с разных кадров; записывай неопределённость и источник в журнале.
8. Визуально проверь коллаж после экспорта PDF, используя `tools/preview_pdf.py`. Не подменяй реальные фотографии сгенерированными изображениями.

Результат: оригиналы, подготовленные копии, выбранное общее фото и проверенное размещение на слайде. Не меняй фото титула без указания пользователя.
