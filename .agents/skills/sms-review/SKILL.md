# Проверка отчёта СМС

1. Прочитай `AGENTS.md`, выбранные карточки и актуальный образец оформления. Проверяй фактический итоговый файл, а не только код генератора.
2. Открой PPTX через python-pptx, PDF через pypdf. Сравни число и порядок страниц, период на титуле и заголовках, имена мероприятий и подтверждённые числа.
3. Проверь отсутствие исключённых событий и старых кварталов; для IV квартала заключительный план должен относиться к I кварталу следующего года.
4. Сверь источники численности. На слайдах рядом с числом не должно быть скобок или формул; соответствующие сведения должны сохраняться в заметках и журнале.
5. Создай изображения страниц: `python tools/preview_pdf.py FILE.pdf --output PREVIEW_DIR`. Открой картинки и визуально проверь обрезанный текст, читаемость, подмену шрифтов, лица у границ коллажа и положение общего фото.
6. Сопоставь со слайдами утверждённого образца. Одного совпадения извлечённого текста недостаточно для подтверждения оформления.
7. При изменении генератора выполни `python -m unittest discover -s webapp -p 'test_*.py' -v`. Пропущенный тест экспорта не считай проверенным PowerPoint/LibreOffice.
8. Для сайта проверь Playwright: карточки, поиск, квартал, кнопки и скачивание. Для GitHub Pages проверь относительные пути под `/newrepository/` и отсутствие запросов к локальному API.

Результат: список исправленных ошибок, пройденные проверки и конкретные ограничения. При отсутствии проверки на Windows не утверждай, что COM-экспорт PowerPoint проверен.
