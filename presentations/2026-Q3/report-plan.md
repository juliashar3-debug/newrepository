Сборка выполнена 15 октября 2026 года. PPTX и PDF обновлены: 11 слайдов, в том числе восемь мероприятий. Пять новых слайдов добавлены, существующий слайд «Гонки героев» перенесен без дублирования. Для каждого включенного мероприятия размещены три фотографии; общий снимок — в среднем блоке коллажа.

## Численность и роли

- Ночная Тула: 23 × 0,75 = 17,25, округлено до 17 участников из СМС.
- Сплав: 22 по фото; участников из СМС — 22 − 2 = 20 по формуле пользователя.
- ЭвоКом: N = 28 по общему фото IMG_6985.jpeg; участников из СМС — N − 8 = 20.
- Ориентирование: N = 13 по общему фото IMG_7454.jpeg; всего — N + 2 = 15, из СМС — 15 − 2 = 13.
- Кубок Тульского дракона: 20/17, Оружейная столица: 38/28, Брейн-ринг: 6/6 — данные пользователя. По фотографиям эти показатели не переопределялись.

Это численность команды пользователя, а не полный охват соревнований. Люди с разных снимков не суммируются. Каждый расчет применяется только к своему мероприятию.

Организатор городских забегов — Тульское беговое сообщество «Тульский Марафон», по указанию пользователя. Для Кубка Тульского дракона сохранены Минспорт Тульской области и областная федерация гребли на байдарках и каноэ. Организатор ориентирования — Тульская федерация спортивного ориентирования. Музей оружия является местом проведения «Брейн-ринга»; СоюзМаш — содействующей стороной, полный состав организаторов источником не установлен.
