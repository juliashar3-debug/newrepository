Подключить владельца GitHub

Редактирование доступно аккаунту juliashar3-debug. Мероприятия и фото сохраняются в открытом репозитории newrepository.

  1. Создайте ключ доступа на GitHub (Fine-grained personal access token).
  2. В Repository access выберите Only select repositories → newrepository.
  3. В Repository permissions: Contents → Read and write, Actions → Read-only. Нажмите Generate token.
  4. Вставьте полученный ключ в поле ниже. Не отправляйте его в чат.

Ключ используется только в этой вкладке и отправляется только GitHub. После перезагрузки страницы потребуется подключиться снова.
