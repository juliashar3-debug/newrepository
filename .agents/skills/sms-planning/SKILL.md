# План следующего квартала

1. Прочитай `AGENTS.md`, `presentations/plans.json` и мероприятия завершаемого периода. Определи следующий квартал через `webapp/report_builder.py:next_quarter`.
2. Подготовь 3–4 пары «цель — конкретная задача»: конкретный формат, аудитория и следующий шаг. Учитывай сезон, доступность и известные интересы участников.
3. Рассмотри обмен опытом, наставничество, интеллектуальный досуг, культуру, добровольчество и доступный спорт. Выбери уместные направления; не включай весь список автоматически.
4. Сравни с прошлым планом: избегай дословного повторения. Продолжение проекта должно содержать новый шаг.
5. Не придумывай бюджет, согласованную дату, партнёра, обещания участников или утверждение руководством. До подтверждения используй `status: proposed` и обозначение «Предложения».
6. Сохрани объект с `report_quarter`, `target_quarter`, `status`, `goals_and_tasks` и датой обновления в `presentations/plans.json`; не удаляй историю прежних кварталов.
7. Сократи формулировки для сохранённых блоков заключительного слайда без изменения его дизайна. Для размещения используй `sms-report`.

Результат: новые связанные пары целей и задач и обновлённая история предложений. Календарные события и сообщения другим людям не создаются без соответствующего запроса пользователя.
