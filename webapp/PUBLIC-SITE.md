# Публичный просмотр через GitHub Pages

Публичная версия показывает мероприятия, фото, предложения плана и готовые PPTX/PDF из репозитория. Она работает без Python на устройстве посетителя. Запись карточек и сборка через PowerPoint выполняются в локальном приложении владельца.

## Публикация

Workflow `.github/workflows/publish-site.yml` собирает сайт и публикует его через GitHub Pages после изменений материалов в `main`. В Settings → Pages нужно выбрать Source → GitHub Actions. В закрытом репозитории доступность Pages зависит от тарифа GitHub. При отсутствии нужных прав автоматическое включение Pages завершится ошибкой; workflow сам не меняет видимость репозитория.

Адрес при успешном включении Pages: `https://juliashar3-debug.github.io/newrepository/`. До успешного завершения Actions → Publish SMS journal этот адрес не подтверждает наличие опубликованного сайта.

16 октября 2026 владелец сделал `newrepository` открытым и включил Pages после ограничения тарифа закрытого репозитория. Публикация через workflow успешно завершилась: сайт размещён на `https://juliashar3-debug.github.io/newrepository/`. Отдельный репозиторий `sms-journal` не используется. Workflow устанавливает Source → GitHub Actions, чтобы автоматическая сборка README из корня ветки не заменяла журнал.

На сайт переносятся только неархивные мероприятия, отмеченные для включения. Оригиналы фото остаются в репозитории; для сайта создаются уменьшенные JPEG без EXIF. База `.data`, заметки карточек, технические пути и исключенные мероприятия в JSON сайта не включаются. Готовые отчеты копируются целиком, включая заметки слайдов PPTX.

Правки локального сайта автоматически в GitHub не отправляются. Перед новой публикацией передайте актуальную выгрузку и материалы агенту для обновления репозитория.

## Проверка локальной сборки

```sh
python -m pip install -r webapp/requirements.txt
python tools/build_public_site.py --output dist
python -m http.server 8000 --directory dist
```

Откройте http://127.0.0.1:8000. Для повторной сборки выберите новый пустой каталог. Пути относительные: сайт работает и в корне домена, и в `/newrepository/`.
