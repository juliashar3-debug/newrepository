# Личный журнал СМС АО ЦКБА

Работающая локальная версия сайта для одного пользователя: мероприятия, форма описания, фотографии, основные показатели и квартальные материалы.

![Журнал мероприятий: карточки, фотографии и готовность к отчету](./docs/events.png)

## Запуск

Нужен Python 3.10 или новее. Установка дополнительных библиотек не обязательна.

Из корня репозитория:

```sh
python3 webapp/server.py --open
```

В Windows после установки Python дважды нажмите `START-WINDOWS.bat` в корне репозитория или `webapp/start-windows.bat`. Браузер откроется автоматически. Скачивать нужно весь репозиторий: начальные сведения и фотографии находятся в `presentations/`.

Откройте **http://127.0.0.1:8765** в браузере. Эта ссылка работает на компьютере, где запущен сервер. Для остановки нажмите Ctrl+C в окне сервера.

## Что уже работает

- При первом запуске импортируются текущий журнал, фотографии и предложения плана из `presentations/`. Восемь мероприятий III квартала отмечены для отчета, исключенная пользователем эстафета остается отдельно.
- Карточки по кварталам, поиск, фильтры готовности, отдельные списки исключенных и архивных мероприятий.
- Создание и редактирование названия, дат, организатора, описания, эффекта, численности команды и СМС, источника и формулы расчетов, заметок и включения в отчет.
- Загрузка нескольких JPG, PNG или WebP, до 20 МиБ каждый. Выбор общего снимка для центра коллажа. Сведения и изменения фотографий применяются после сохранения формы.
- Неизвестные поля можно оставить пустыми. Сервер проверяет даты, квартал, целые неотрицательные количества и соотношение численности СМС и команды. Для расчетных значений требуется основание.
- Повторная загрузка одинакового файла в одну карточку не создает дубль. Оригиналы не растягиваются и не перезаписываются. При наличии Pillow автоматически создаются отдельные уменьшенные изображения для просмотра.
- Карточку можно отправить в архив и восстановить. Удаление фотографии из карточки не стирает исходный файл.
- Раздел квартального отчета содержит ссылки на уже собранные PPTX и PDF. После изменения карточек показывается, что материалы изменились после сборки.
- Выгрузка журнала в JSON и полного квартального архива ZIP с исходными фотографиями и планом. В JSON сохраняются источники импортированных показателей.
- Защита от потери правок при одновременном редактировании в разных вкладках.

## Где хранятся изменения

В `webapp/.data/`: база `journal.sqlite3`, оригиналы новых загрузок в `uploads/`, уменьшенные копии в `thumbnails/`. Каталог исключен из Git. Для резервной копии остановите сервер и сохраните всю папку `.data/`; архив квартала также сохраняет сведения и используемые фотографии.

Начальные данные импортируются один раз при создании базы. Уже внесенные на сайте правки не перезаписываются при следующем запуске. Изменения сайта **не перезаписывают автоматически** `presentations/events.json` и готовые PPTX/PDF. Для работы агента выгрузите ZIP квартала и передайте его с просьбой обновить отчет по AGENTS.md.

Другой каталог данных и порт можно выбрать явно:

```sh
python3 webapp/server.py --port 8766 --data-dir /путь/к/данным
```

## Текущие границы

Это локальная версия для одного пользователя. Авторизация ChatGPT и доступ по закрытой интернет-ссылке пока не подключены. Сервер слушает только `127.0.0.1` и принимает локальные имена хоста.

Сборка новой PPTX и PDF выполняется агентом по выгруженным материалам. Кнопки скачивания на сайте отдают существующие готовые файлы и не создают видимость автоматической пересборки.

Для доступа по интернет-ссылке потребуется отдельно настроить размещение, постоянное хранение данных и авторизацию владельца. Публикация в интернете пока не выполнена.

## Проверка

```sh
python3 -m unittest discover -s webapp -p 'test_*.py' -v
node --check webapp/static/app.js
```

Девять проверок охватывают HTTP-обработчики в памяти, реальные операции базы и файлов: импорт, сохранение после повторного открытия, валидацию, конфликт версий, загрузку и дедупликацию фото, ZIP, архивирование, выдачу PDF и отклонение посторонних запросов. Интерфейс также проверен в Chromium: список мероприятий, форма с фотографиями и раздел отчета; ошибок JavaScript не обнаружено. При проверке браузера запросы направлялись непосредственно в обработчик, без сетевого сервера. Запуск через TCP в этой среде не проверен. Проверки не затрагивают рабочие данные пользователя.
